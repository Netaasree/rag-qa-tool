# Inline Citation Strategy & Standard

## Goal
Answers generated by the RAG system should cite which retrieved chunk each claim came from inline, formatted like:
`"The RAG pipeline uses RAPTOR [chunk 12] to improve retrieval."`

---

## Standard Specifications

| Component | Standard Specification | Notes |
| :--- | :--- | :--- |
| **Context Chunk Label** | `[chunk {chunk_index}] <chunk text>` | Sourced from ChromaDB chunk metadata (`chunk_index`). |
| **Inline Citation Format** | `[chunk N]` | Placed immediately after each factual claim or statement. |
| **Coverage Requirement** | Every factual sentence / claim | Prevents partial or front-loaded citation behavior. |
| **Fallback Guardrail** | `"I don't know based on the provided documents"` | Mandatory response when context lacks the answer (no citations). |
| **Hallucination Guardrail** | Copy visible labels only | Model must never invent or extrapolate chunk numbers not in Context. |

---

## Approach & Implementation

1. **Context Block Labeling**:
   When building the context block passed to Gemini, prepend each retrieved chunk with its `chunk_index` metadata:
   ```text
   [chunk 12] <chunk text>

   ---

   [chunk 7] <chunk text>
   ```

2. **Explicit Prompt Instruction**:
   Instruct the model to cite the chunk number inline after every claim it makes, mirroring the exact `[chunk N]` format:
   ```text
   Cite the chunk number inline after any claim or statement you make, using the exact [chunk N] format corresponding to where the information was found (e.g., "The RAG pipeline uses RAPTOR [chunk 12] to improve retrieval."). Every factual sentence must end with or include its inline chunk citation.
   ```

3. **Fallback Preservation**:
   Keep the anti-hallucination fallback instruction intact:
   ```text
   If the answer cannot be determined strictly from the provided Context, you MUST respond with the exact phrase:
   "I don't know based on the provided documents"
   ```
   The citation requirement never overrides or weakens this rule.

---

## Why This Approach

- **Zero Hallucination of Chunk IDs**:
  Keeping chunk labels consistent between the context block (`[chunk 12]`) and the citation format (`[chunk 12]`) means the model only has to copy a number it already sees in the prompt, not synthesize or guess one from memory.
- **Granular Traceability**:
  Inline citations (as opposed to a generic sources list at the end of the response) clarify exactly which claim is supported by which passage.
- **Realistic Demonstration Value**:
  Matches how production citation-grounded RAG systems operate for auditability and verification.

---

## Known Risks & Mitigation

- **Risk**: The model may cite inconsistently (e.g., citing only the first sentence and omitting citations for subsequent claims).
- **Mitigation**: The prompt instruction explicitly mandates: *"Every factual sentence must end with or include its inline chunk citation."* If testing reveals omission under certain models or prompts, reinforce the instruction to demand a citation tag per sentence.

## Reference Implementation

```python
from typing import List, Dict, Any, Optional


def construct_grounded_prompt(
    question: str,
    context_chunks: List[str],
    metadatas: Optional[List[Dict[str, Any]]] = None
) -> str:
    formatted_chunks = []
    for i, doc in enumerate(context_chunks):
        chunk_idx = None
        if metadatas and i < len(metadatas) and isinstance(metadatas[i], dict):
            chunk_idx = metadatas[i].get("chunk_index")
        if chunk_idx is None:
            chunk_idx = i
        formatted_chunks.append(f"[chunk {chunk_idx}] {doc}")

    joined_context = "\n\n---\n\n".join(formatted_chunks)

    prompt = f"""You are an accurate, reliable question-answering assistant. Your answers must be grounded strictly in the provided context documents with inline citations.

Context:
{joined_context}

Question:
{question}

Instructions:
1. Answer the question using ONLY the facts directly mentioned in the Context above.
2. Cite the chunk number inline after any claim or statement you make, using the exact [chunk N] format corresponding to where the information was found (e.g., "The RAG pipeline uses RAPTOR [chunk 12] to improve retrieval."). Every factual sentence must end with or include its inline chunk citation.
3. If the answer cannot be determined strictly from the provided Context, you MUST respond with the exact phrase:
   "I don't know based on the provided documents"
   Do not provide citations or partial answers when responding with this phrase.
4. Do not speculate, extrapolate, or use any outside knowledge not present in the Context.
5. Only cite chunk numbers that are explicitly provided in the Context above (e.g., [chunk 12]). Never fabricate or hallucinate chunk numbers.
6. Keep the answer clear, concise, and factual.
"""
    return prompt
```
